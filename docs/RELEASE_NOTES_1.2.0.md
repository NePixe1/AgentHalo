# Agent Halo 1.2.0

## Windows 监控

- 新增 OpenCode：通过内嵌插件和本地原子快照识别思考、工具执行、授权等待、完成和故障，展示会话、模型、输入输出及上下文占用。首次安装插件后需重启已经打开的 OpenCode。
- 新增 WorkBuddy：只读本地活会话、数据库和响应日志，不安装 hook、不修改 WorkBuddy 配置。展示原生任务状态、模型、最近一次响应输入输出和上下文。
- 修复 Pi 和 OpenCode 部分运行中进程被误判为退出的问题，校验进程创建时间以避免 PID 复用；改善 Pi 恢复会话选择和长任务检测。
- 保留已有监控对象勾选记录，新对象可在菜单中启用。

## 面板与交互

- 调整状态文字和 Agent 切换过渡，避免白闪、透明度突变和较大的位移。
- 将 Codex 扫描与界面读取解耦，减少切换时等待后台扫描锁的卡顿。
- 统一任务区左对齐与分割线；模型、输入和输出使用紧凑标签，输入为蓝色、输出为青绿色。
- 无会话状态沿用相同分割线和内容起点，不再显示独立虚线框。
- 内嵌 OpenCode 插件及 WorkBuddy 图标，安装包不依赖外置资源或 sqlite3.exe。

## 平台范围与限制

- macOS 同步 OpenCode 插件快照与 WorkBuddy 只读监控，并沿用同一套状态含义。面板任务区去掉独立虚线框，输入为蓝色、输出为青绿色；未选中的 WorkBuddy 图标灰显。Codex 扫描锁解耦仍只在 Windows。
- WorkBuddy 本地存储并非稳定公共 API，暂不保证远程或云端任务检测。
- 输入输出展示最近一次有效响应用量，不代表累计账单；缺少数据时不伪造数字。
- 自动化测试覆盖生命周期归约、进程存活、用量、切换和布局；授权与异常分支仍需真实交互验收。

## 安装

- Windows：完整解压 `AgentHalo-Windows-v1.2.0.zip` 后运行 `AgentHalo.exe`，需要 .NET Framework 4.8。
- macOS：对应构建产物为 `AgentHalo-macOS-1.2.0.dmg`，以发布页实际提供的附件为准。
